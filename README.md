# To-Do List

**Боровский Максим Олегович · 367916 · К3344**

Небольшой учебный проект (HTML/CSS/JS). Список задач с сохранением в `localStorage` и изменением порядка через drag-and-drop.

## Функционал
- Добавление задачи (название + дата)
- Редактирование (название и дата)
- Удаление задачи
- Отметка «выполнено» с визуальным отличием
- Фильтры: все / активные / выполненные
- Сортировка по дате и по времени создания
- Поиск по названию (и дате в формате `ГГГГ-ММ-ДД`)
- Перестановка задач **drag-and-drop**
- Сохранение задач и порядка в `localStorage`
- Фавикон и интерфейс формируются через JS (без фреймворков)
